# Roadmap de Desenvolvimento - BioConecta (Mini Sistema Web de Biologia)

Este documento registra o planejamento, etapas e progresso de implementação do mini sistema web para apoio ao ensino e aprendizagem da disciplina de Biologia.

---

## 📌 Status das Etapas de Desenvolvimento

- [x] **1. Planejamento**
  - Definição do escopo, requisitos de professor e aluno, modelo de dados e fluxos de navegação.
- [x] **2. Definição das funcionalidades**
  - Especificação detalhada de autenticação, dashboards, gestão de conteúdos (CRUD), atividades avaliativas, banco de questões e filtros.
- [x] **3. Criação da estrutura do projeto**
  - Organização de pastas (`frontend/`, `css/`, `js/`, `assets/`, documentação e configuração de deploy).
- [x] **4. Desenvolvimento da página inicial (Landing Page)**
  - Banner institucional da disciplina de Biologia, apresentação de recursos, diferenciais pedagógicos e chamadas para ação (CTA).
- [x] **5. Desenvolvimento do Login**
  - Telas e formulários de autenticação com separação de perfis (Professor e Aluno) e preenchimento rápido para demonstração acadêmica.
- [x] **6. Desenvolvimento do Dashboard do Professor**
  - Indicadores gerais (conteúdos, atividades, alunos cadastrados, pendências), atalhos rápidos e visão das turmas.
- [x] **7. Desenvolvimento do Dashboard do Aluno**
  - Resumo de atividades pendentes/concluídas, progresso em conteúdos, média de desempenho e acessos rápidos aos materiais.
- [x] **8. Desenvolvimento dos conteúdos de Biologia**
  - Listagem com cards modernos, filtros por temas (Citologia, Genética, Ecologia, Evolução, Fisiologia, etc.), busca em tempo real, modal de leitura detalhada com referências e CRUD completo para o professor.
- [x] **9. Desenvolvimento das atividades**
  - Criação de atividades com prazos, pontuação e questões de múltipla escolha; tela interativa para o aluno resolver e obter pontuação imediata com gabarito comentado; acompanhamento de submissões pelo professor.
- [x] **10. Desenvolvimento do banco de questões**
  - Repositório de questões com nível de dificuldade (Fácil, Médio, Difícil), explicações detalhadas pedagógicas, simulador de treino para alunos e cadastro de novas questões pelo professor.
- [x] **11. Implementação da busca e filtros**
  - Sistema reativo de filtragem por termos, temas botânicos/zoológicos/celulares e nível de complexidade em todas as telas.
- [x] **12. Responsividade e Acessibilidade**
  - Adaptação completa para desktop, notebook, tablets e smartphones (menu mobile retrátil, grid flexível e tipografia fluida).
- [x] **13. Testes**
  - Validação funcional de login, persistência no LocalStorage, cálculo de notas, submissão de respostas e CRUD completo.
- [x] **14. Correção de erros e Refinamentos Visuais**
  - Tratamento de estados vazios, feedback visual (toasts), paleta biológica harmoniosa e validações de formulário.
- [x] **15. Publicação no GitHub**
  - Repositório oficial publicado: [https://github.com/luiz2k2/biologia](https://github.com/luiz2k2/biologia)
- [x] **16. Deploy na Vercel**
  - Aplicação publicada com sucesso: [https://biologia-frontend.vercel.app/](https://biologia-frontend.vercel.app/)
- [x] **17. Teste final do sistema em produção**
  - Validação dos links públicos em dispositivos reais e preenchimento final dos links no README.

*Todas as 17 etapas foram concluídas com sucesso.*
